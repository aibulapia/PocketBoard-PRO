1. 개요 — 무엇을 하는 앱인가

1-1. 한 줄 요약

주말·공휴일에 여러 공장에서 동시에 진행되는 공사를, 감독자들이 휴대폰 하나로 점검하고 보고할 수 있게 만든 현장 안전관리 앱입니다.

1-2. 어떻게 쓰나

  1. 마스터가 주말공사 엑셀 파일을 앱에 올립니다 (주 2회, 수·금 오후)
  2. 감독자는 링크를 열어 자기 담당 공장의 오늘 공사 목록을 봅니다
  3. 현장에서 점검하며 공사위치·인원·체감온도를 입력합니다
  4. 버튼 한 번으로 안전보고문이 완성되고, 카톡으로 복사해 보고합니다
  5. 다음 날 오전 6시에 자동으로 초기화되어, 그날의 점검을 새로 시작합니다

1-3. 설치가 필요 없습니다

앱스토어에서 받는 앱이 아니라 인터넷 주소(링크)만 있으면 바로 열립니다. 휴대폰 홈 화면에 바로가기를 만들어두면 앱처럼 쓸 수 있습니다.

2. 왜 만들었나

2-1. 기존의 어려움

문제 내용
종이·엑셀 의존 주말 현장에서 종이 출력물이나 엑셀 파일을 들고 다녀야 했음
보고문 수기 작성 매번 같은 형식을 손으로 다시 작성
체감온도 계산 폭염 시 온·습도로 체감온도를 따로 계산해야 함
현황 파악 어려움 지금 몇 건이 진행 중인지 한눈에 안 보임

2-2. 해결한 것

  • 엑셀 한 번 올리면 모든 감독자 휴대폰에 자동 반영
  • 입력하면 안전보고문이 자동 완성 — 형식 고민 불필요
  • 온·습도 입력하면 체감온도와 폭염 단계가 자동 계산
  • 공장별 진행 현황이 탭 숫자로 즉시 표시

3. 누가 쓰는가 — 권한 3단계

단계 이름 누가 할 수 있는 것
레벨1 감독자 현장 안전 감독자 공사 점검·입력, 보고문 작성, 체감온도 측정, 긴급공사 등록
레벨2 관리자 공장 관리자 위 전부 + 감독자 연락처 조회·전화 연결, 공지사항 작성
레벨3 마스터 안전보건 담당 실장 위 전부 + 엑셀 업로드, 전체 초기화, 접속현황 조회, 연락처 관리

로그인이 없습니다. 감독자는 링크만 열면 바로 씁니다. 관리자·마스터 기능이 필요할 때만 코드를 입력해 권한을 엽니다. 한 번 인증하면 그 휴대폰에서는 계속 유지됩니다.

4. 기능 총망라

4-1. 공사 목록 화면

기능 설명
공장별 탭 9개 공장(1~5공장, 6 PT, 7 소재, 8 아산, 9 기타)을 탭으로 구분
내 담당 공장 설정 감독자는 자기 공장 1개만 선택 (관리자·마스터는 여러 개 가능)
날짜 넘겨보기 ◀ ▶ 버튼으로 다른 날 예정 공사 미리 확인
TODAY 배지 오늘 인원이 배정된 공사에 표시
진행 현황 숫자 탭마다 "진행중/전체" 건수 표시
즐겨찾기 ★ 관심 공사를 찜해두면 자기 공장 탭에서 위로 올라옴
기상 정보 현재 기온·습도·기상특보 확인

4-2. 공사 점검 화면

기능 설명
공사위치·담당감독자 현장에서 직접 입력
인원 입력 직영·일용·협력업체 인원, 65세 이상 고령자 여부
체감온도 계산 온·습도 입력 → 체감온도와 폭염 단계 자동 산출
작업 연장 예정 시간을 넘겨 작업할 때 연장 시각 기록
안전보고문 자동 작성 공사 전/중/후 단계별로 형식에 맞춰 자동 생성
카톡 복사 버튼 한 번으로 보고문을 복사해 카톡에 붙여넣기
되돌리기 🗑️ 잘못 입력했을 때 그 카드만 공사 전 상태로 초기화

4-3. 긴급공사 등록

목록에 없던 공사가 갑자기 생겼을 때, 현장에서 바로 등록합니다.

5단계 마법사: 공장 → 작업 위치 → 작업 내용 → 작업 구분 → 담당 감독자 선택만 하면 공사명이 자동으로 만들어집니다.

등록된 긴급공사는 일반 공사와 똑같이 점검·기록할 수 있고, 그 주 공사기간이 끝나면 자동으로 정리됩니다.

4-4. 관리자 기능 (레벨2 이상)

  • 감독자 연락처 조회 및 전화 바로 걸기
  • 공지사항 작성 (감독자 앱에 팝업으로 표시)
  • 공지에 링크를 넣으면 자동으로 눌러지는 링크가 됩니다

4-5. 마스터 기능 (레벨3)

기능 설명
엑셀 업로드 주말공사 엑셀 파일을 올리면 전원에게 자동 반영
전체 초기화 목록 전체를 비움 (암호 재확인 필요)
접속 현황 최근 7일간 공장별·등급별 접속 대수 확인
복수공장 설정 현황 여러 공장을 담당으로 설정한 기기 파악
연락처 관리 감독자 연락처 추가·삭제
전체 내보내기 기록 전체를 엑셀로 내려받기
회사명 수정 앱에 표시되는 회사명 변경

4-6. 기타

  • 다크모드 — 야간 현장에서 눈부심 감소
  • 익명 게시판 — 건의사항·의견을 로그인 없이 남길 수 있는 창구
  • 도움말 — 앱 안에서 사용법 확인

5. 06시 일일 체계 — 이 앱의 심장

5-1. 왜 자정이 아니라 06시인가

주말 공사는 밤을 넘겨 새벽까지 이어지는 경우가 많습니다. 자정을 기준으로 날짜를 바꾸면, 새벽 2시에 작업 중인 감독자의 화면이 갑자기 "다음 날"로 바뀌어 그날 입력이 사라진 것처럼 보입니다.

그래서 이 앱은 오전 6시를 하루의 경계로 삼습니다.

실제 시각 앱이 보는 날짜
8월 27일 새벽 3시 8월 26일 (아직 전날 근무 중)
8월 27일 오전 7시 8월 27일

5-2. 06시에 자동으로 일어나는 일

  • 공사중 → 공사전으로 초기화
  • 작업 연장 기록 해제
  • 수동으로 켠 TODAY 표시 해제
  • 공사기간이 끝난 공사는 목록에서 자동 정리

체감온도 기록은 지워지지 않고 보존됩니다 (이력·백업에 활용).

6. 시스템 구조

6-1. 전체 그림

   감독자 휴대폰
        ↓  (인터넷 주소로 접속)
   Cloudflare Pages  ← 앱 화면 제공
        ↓
   Supabase (데이터베이스)  ← 공사 목록·연락처·공지 보관
        ↓  (매일 새벽 5시)
   구글 시트  ← 자동 백업

6-2. 각 부분이 하는 일

구성 역할
Cloudflare Pages 앱 화면을 감독자 휴대폰에 전달. 무료·자동 HTTPS
Supabase 공사 목록, 감독자 연락처, 공지사항, 접속 기록 보관
구글 앱스스크립트 체감온도 기록 전송 + 매일 새벽 자동 백업
구글 시트 백업 데이터 보관 (사고 시 복구용)

6-3. 배포 방식

앱 파일을 GitHub에 올리면 Cloudflare가 자동으로 감지해 배포합니다. 감독자는 앱을 다시 설치할 필요 없이, 다음에 열면 새 버전이 뜹니다.

7. 운영 방식

7-1. 주간 흐름

시점 하는 일 누가
수요일 오후 주말공사 엑셀 업로드 마스터
금요일 오후 변경사항 반영해 재업로드 마스터
토·일·공휴일 현장 점검 및 보고 감독자
매일 새벽 5시 자동 백업 시스템
매일 오전 6시 일일 자동 초기화 시스템

7-2. 감독자가 해야 할 일

  1. 앱 열기 (홈화면 바로가기 권장)
  2. 최초 1회 — 내 담당 공장 선택
  3. 현장에서 점검하며 입력
  4. 보고문 복사해 카톡 보고

그 외 설정은 필요 없습니다.

8. 데이터·보안 원칙

8-1. 여러 사람이 동시에 써도 안전하게

여러 감독자가 각자 휴대폰에서 동시에 입력합니다. 저장할 때마다 서버의 최신 내용과 합쳐서 저장하므로, 다른 사람이 방금 입력한 내용이 지워지지 않습니다.

8-2. 개인정보 보호

  • 접속 통계는 개인을 식별하지 않습니다. 기기를 구분하는 임의 번호만 사용
  • 감독자 연락처는 관리자 이상만 조회 가능
  • 연락처·접속기록은 직접 접근이 차단되어 있고, 정해진 통로로만 조회됩니다

8-3. 데이터 보호 조치

조치 상태
공사 목록 삭제 차단 ✅ 적용
연락처·접속기록 직접 접근 차단 ✅ 적용
매일 자동 백업 ✅ 적용
HTTPS 암호화 통신 ✅ 적용 (자동)

8-4. 구조적 한계 — 솔직히 밝힙니다

이 앱은 로그인이 없어서 누구나 바로 쓸 수 있는 대신, 주소를 아는 사람이 공사 목록을 들여다볼 가능성을 완전히 막을 수는 없습니다.

공사 목록에는 개인정보가 들어있지 않습니다 (공사명·위치·인원수). 개인정보인 연락처는 별도로 차단되어 있습니다.

완전한 차단은 로그인 도입이 필요하며, 이는 현장 사용성과 맞바꾸는 문제입니다.

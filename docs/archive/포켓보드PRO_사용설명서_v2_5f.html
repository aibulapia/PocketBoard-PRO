📱 앱 개요

현대자동차 협력 정비업체(MMEEC) 소속 안전감독자들이 주말·휴일 현장 안전점검을 기록·공유하기 위한 웹 앱(PWA)입니다.

대상 현장: 12개 공장(1~5공장, 엔진·변속기·소재·기타·아산·남양·광명)

핵심 목적: 감독자 여러 명이 같은 공사 목록을 실시간으로 함께 보고, 각자 체크한 내용이 서로에게 즉시 반영되도록 하는 것

접속 방법: 별도 설치 없이 브라우저로 바로 사용, 홈 화면에 아이콘 추가(PWA 설치)도 가능

🔑 권한 3단계

코드 입력 없이 앱을 열면 누구나 감독자(레벨 0)로 시작합니다. 관리자 코드를 입력하면 권한이 올라갑니다.

레벨이름진입 방법할 수 있는 것
Lv.0 감독자 기본 (코드 불필요) 공사 목록 조회·체크(TODAY·즐겨찾기)·상세 입력·안전보고문·카톡복사·엑셀 다운로드(현재 목록만)
Lv.1 관리자 🔑 관리자 모드 → 코드 입력 Lv.0 전부 + 공지사항 작성 + 감독자 연락처 조회·추가(전화 걸기 가능)
Lv.2 최고관리자(마스터) 🔑 관리자 모드 → 최고관리자 코드 입력 Lv.1 전부 + 전체 현장 통합 엑셀 다운로드 + 연락처 삭제 + 엑셀 업로드(파일변경) + 전체 초기화
인증은 기기에 30일 저장됩니다 한 번 코드를 입력하면 같은 기기·같은 브라우저에서는 30일간 다시 묻지 않습니다. 인증을 풀려면 관리자 모드 팝업에서 "인증 해제"를 누르면 됩니다.

📋 공사 목록 화면

공장 탭 필터

화면 상단 탭으로 "전체" 또는 특정 공장만 걸러볼 수 있습니다. 감독자 설정에서 "내 공장"을 지정하면 앱을 열 때 그 공장이 자동으로 먼저 보입니다.

정렬 순서 (자동, 4단계 우선순위)

  1. TODAY(오늘 배정) + 즐겨찾기 ★
  2. TODAY(오늘 배정)만
  3. 즐겨찾기 ★만
  4. 나머지 — 공정(프레스 → 차체 → 도장 → 의장) → 엑셀에 있던 원래 순서
목록이 갑자기 움직이지 않습니다 한 번 정렬된 순서는 그 화면을 다시 불러올 때까지 고정됩니다(스냅샷 방식). 카드를 체크해도 그 자리에서 색만 바뀔 뿐, 목록이 재정렬되어 화면이 흔들리지 않습니다.

카드 상태 배지

TODAY / TODAY 2일째… ★ 즐겨찾기 OO시연장 종료 / 확인필요

공사전 → 공사중 → 종료(또는 17시 이후 "확인필요") 순서로 상태가 바뀝니다. TODAY 배지는 직접 터치해서 파란색(활성)↔회색(취소)으로 전환할 수 있습니다.

날짜 이동

◀ ▶ 화살표로 날짜를 넘겨볼 수 있고, 가운데 날짜를 터치하면 바로 오늘로 돌아옵니다. 각 날짜마다 그날 배정된 인원 수가 함께 표시됩니다.

공사 추가

현장에서 엑셀에 없던 공사가 갑자기 생기면 "＋ 공사추가" 버튼으로 누구나(감독자 포함) 새 카드를 만들 수 있습니다.

⭐ TODAY·즐겨찾기

TODAY

오늘 날짜에 인원이 배정된 공사는 자동으로 TODAY 배지가 붙습니다. 배지를 직접 터치해 끄고 켤 수 있고, 연속으로 며칠째 진행 중인지 "n일째"로 표시됩니다(2일째부터). 06시가 지나면 자동으로 리셋되고, 수동으로 껐던 상태는 재사용됩니다.

즐겨찾기

관심 있는 공사를 ★로 여러 개 찜해두면 목록 맨 위로 모아 보여줍니다. 다시 누르면 해제되고, 공사기간이 끝나거나 전체 초기화를 하면 자동으로 정리됩니다. 기기별 로컬 저장이라 사람마다 다르게 설정할 수 있습니다.

🌤️ 폭염·기상 정보

헤더의 🌤️ 버튼을 누르면 팝업으로 실시간 기온·습도(기상청 초단기실황 API)와 특보 정보를 볼 수 있습니다. 2시간 캐시로 동작하며 10분마다 최신 여부를 확인합니다.

카드에서 체감온도·습도를 입력하면 자동으로 폭염 단계(관심·주의·경고·위험)를 계산해 표시합니다. 이 기록은 06시가 지나도 데이터 자체는 보존되어 백업·이력에 활용됩니다(화면 표시만 리셋).

⏰ 작업연장

17시 이후에도 공사가 계속되면 상세 화면의 "⏰ 작업연장"에서 종료 예정 시각을 선택합니다(18~23시, 00~05시 1시간 단위). 선택하면 카드에 "OO시연장" 배지가 뜨고, 카톡복사·안전보고문에도 자동 반영됩니다. 연장 선택을 안 하면 17시 이후 "확인필요" 상태로 바뀝니다.

📋 안전보고문·카톡복사

안전보고문 (5공장 전용 생성, 상세화면은 전 공장 가능)

공사전/공사중/종료 단계를 선택하면 작업 내용·체감온도·폭염대책을 자동으로 정리한 보고문을 만들어줍니다.

  • 공사전 복사: 그날 최초 기록된 체감온도 자동 삽입
  • 공사중 복사: 12:00~14:00 사이 최초 기록 자동 삽입
  • 해당 시간대 기록이 없으면 경고 팝업 후 복사가 중단됩니다

카톡 복사

"💬 카톡복사"를 누르면 공사명·위치·감독자·인원이 정리된 텍스트가 클립보드에 복사됩니다. 카톡방에 붙여넣기만 하면 됩니다.

🔑 관리자 기능 (Lv.1 이상)

공지사항

전체 사용자에게 보여줄 공지를 작성·저장합니다. 저장하면 모든 사용자 화면에 자동으로 팝업됩니다. 비워두면 공지가 표시되지 않습니다.

감독자 연락처

이름·연락처·부서·공장을 등록하면 감독자 카드에 전화 버튼이 표시됩니다. 연락처는 서버에만 보관되고 일반 사용자 기기로는 전송되지 않습니다. 부서·공장은 오타 방지를 위해 목록에서만 고를 수 있습니다.

🔐 최고관리자 기능 (Lv.2)

📊 전체 현장 통합 엑셀
모든 공장 데이터를 하나의 엑셀로 다운로드 (세션별 시트 탭 구성)

＋ 파일변경 (엑셀 업로드)
새 주말공사 엑셀을 업로드해 목록을 갱신 (기존 입력값은 유지되며 병합됨)

초기화
전체 목록·정렬·즐겨찾기를 완전히 비움. 새 시즌 시작 전 사용 권장

연락처 삭제
등록된 감독자 연락처를 삭제 (Lv.1은 조회·추가만 가능)

새 엑셀 업로드 워크플로우 권장 새로운 주말공사 시즌을 시작할 때는 초기화 → 파일변경(엑셀 업로드) 순서를 권장합니다. 초기화 없이 바로 새 엑셀만 올리면 기존 목록과 병합되어, 이전 시즌 카드가 함께 남아있을 수 있습니다.

💾 데이터 저장 원칙

실시간 공유

모든 기록은 서버(Supabase) 한 곳에 저장되어, 누가 어디서 체크하든 전원에게 똑같이 보입니다. 화면에 보이는 범위만 "내 공장" 설정이나 권한에 따라 달라집니다.

카드 단위 병합 저장

저장은 카드 하나하나마다 "마지막으로 고친 시각"을 기준으로 병합됩니다. 예전에는 목록 전체를 통째로 덮어써서 다른 사람이 방금 한 체크가 지워지는 사고가 있었는데, 지금은 카드별로 비교해 더 최신 것만 반영되므로 이런 문제가 없습니다.

🌙 06시 일일 체계

이 앱의 "하루"는 06:00 ~ 다음날 05:59로 통일되어 있습니다. 06시가 지나면 자동으로:

  • "공사중" 상태였던 카드가 "확인필요"로 전환
  • 전날 작업연장 선택이 초기화
  • TODAY 수동 취소 상태가 리셋 (다시 자동 판정)
  • 체감온도 화면 표시가 리셋 (데이터 자체는 보존)

앱을 켜둔 상태에서도 분 단위로 시각을 감지해 자동으로 전환되며, 새로고침이 필요 없습니다.

📡 오프라인 지원

현장에서 신호가 약해도 앱 자체는 계속 열립니다(서비스워커로 화면 캐시). 저장 중 통신이 안 되면 자동으로 대기열에 넣어두고, 신호가 돌아오면(또는 30초마다 자동 재시도) 저장을 이어서 완료합니다. 이 과정에서도 카드 단위 병합이 적용되어 다른 사람의 기록을 덮어쓰지 않습니다.

❓ 자주 묻는 질문

내가 체크한 게 다른 사람에게도 보이나요?

네. 모든 기록은 한 곳에 저장되어, 누가 어디서 체크하든 전원에게 똑같이 보입니다. 화면에 보이는 범위만 내 공장 설정이나 권한에 따라 달라질 뿐입니다.

내 공장 설정은 왜 필요한가요?

담당 공장을 정하면 그 공장만 걸러보고, 앱을 열 때 첫 화면으로 자동 표시됩니다.

TODAY 배지가 뭔가요?

오늘 배정된 공사에 파란 배지가 붙습니다. 터치하면 회색(취소)↔파랑 전환되고, 2일째부터 "N일째"도 표시됩니다.

날짜 이동은 어떻게 하나요?

◀▶ 화살표로 넘기고, 가운데 날짜를 터치하면 오늘로 바로 이동합니다.

즐겨찾기는 뭔가요?

관심 있는 공사를 여러 개 찜해두면 목록 맨 위에 모아 보여줍니다. ★를 다시 누르면 해제되고, 공사기간이 끝나거나 전체 초기화하면 자동으로 정리됩니다.

"안전보고문"은 뭔가요?

5공장 전용 기능. 공사전/중/종료 단계별로 작업·체감온도·폭염대책을 자동으로 정리해줍니다. "안전보고문 생성"을 누르면 내용을 확인·수정할 수 있는 창이 뜨고, 거기서 클립보드로 복사합니다. 체감온도 기록이 없어도 생성할 수 있습니다. 상세화면은 전 공장 사용 가능합니다.

공사 연장은 어떻게 하나요?

17시 이후 계속되면 "⏰ 작업연장"에서 종료 시각을 선택하세요. 카드·카톡복사·보고문에 자동 반영됩니다.

카톡 복사는 어떻게 하나요?

"💬 카톡복사" 누르면 공사명·위치·감독자·인원이 정리돼 클립보드에 복사됩니다. 카톡방에 붙여넣기만 하면 됩니다.

공사기간이 지난 목록은 언제 사라지나요?

자동으로 사라지지 않습니다. 새로운 시즌을 시작할 때 최고관리자가 "초기화" 버튼을 눌러 정리하는 방식입니다.

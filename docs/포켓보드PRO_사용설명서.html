1. 시작하기

앱 열기

앱스토어에서 받을 필요 없습니다. 링크만 열면 바로 사용할 수 있습니다.

주소: https://pocketboardprov2.pages.dev/

홈 화면에 추가하면 편합니다
크롬에서 앱을 연 뒤 오른쪽 위 ⋮ 메뉴 → "홈 화면에 추가"를 누르면 앱 아이콘처럼 바로 열 수 있습니다.

처음 한 번 — 내 담당 공장 선택

앱을 처음 열면 담당 공장을 고르는 창이 뜹니다. 감독자는 1개만 선택할 수 있습니다. 선택해야 다음으로 넘어갑니다.

나중에 바꾸려면 상단의 🏭 내 공장 버튼을 누르면 됩니다.

3. 공사 점검하기

공사 카드를 누르면 상세 화면이 열립니다.

항목설명
공사위치실제 작업 위치를 입력 (예: 1층 d11)
담당 감독자목록에서 선택. 관리자 이상은 전화 버튼도 표시됨
인원직영 · 일용 · 협력업체 인원수
65세 이상고령자 있으면 체크 후 인원 입력
메모특이사항 기록
작업 연장예정 시간을 넘길 때 연장 시각 기록
잘못 입력했다면
상세 화면 아래 🗑️ 버튼을 누르면 그 공사만 처음 상태로 되돌립니다. (체감온도 기록은 지워지지 않습니다)

4. 체감온도 측정

공사 상세 화면에서 🌡️ 체감온도 계산을 누릅니다.

  1. 현재 온도와 습도를 입력
  2. 체감온도와 폭염 단계(관심 / 주의 / 경고 / 위험)가 자동 계산
  3. 기록하면 안전보고문에 자동으로 들어갑니다

상단 🌤️ 아이콘을 누르면 현재 기상 정보와 기상특보도 확인할 수 있습니다.

5. 안전보고문 · 카톡 보고

입력을 마치면 보고문이 자동으로 완성됩니다. 형식을 외울 필요가 없습니다.

단계별 보고문

단계언제

공사 중작업 진행 중 점검 시
공사 후작업 종료 후 정리정돈 확인

카톡으로 보내기

  1. 보고문 아래 복사 버튼 누르기
  2. 카톡 열어서 붙여넣기
필수 입력 항목
공사명 · 공사위치 · 담당 감독자를 입력해야 보고문이 만들어집니다.

6. 긴급공사 등록

목록에 없던 공사가 갑자기 생겼을 때 현장에서 바로 등록합니다.

상단 + 공사추가 → 긴급공사 등록

5단계로 등록

  1. 공장 선택
  2. 작업 위치
  3. 작업 내용
  4. 작업 구분
  5. 담당 감독자

선택만 하면 공사명이 자동으로 만들어집니다.

등록된 긴급공사는 일반 공사와 똑같이 점검·보고할 수 있고, 그 주 공사기간이 끝나면 자동으로 정리됩니다.

7. TODAY · 즐겨찾기

TODAY 배지

오늘 인원이 배정된 공사에 자동으로 붙습니다. 인원 배정이 없는 공사를 오늘 목록에 추가하려면 + 공사추가 → 당일 공사 추가를 사용합니다.

즐겨찾기 ★

관심 있는 공사를 찜해두면 내 공장 탭에서 맨 위로 올라옵니다. ★를 다시 누르면 해제됩니다.

공사기간이 끝나거나 전체 초기화하면 자동으로 정리됩니다.

8. 06시 일일 초기화

이 앱의 하루는 자정이 아니라 오전 6시에 바뀝니다.

주말 공사는 밤을 넘겨 새벽까지 이어지는 경우가 많습니다. 자정에 날짜가 바뀌면 새벽 작업 중에 화면이 다음 날로 넘어가버립니다. 그래서 오전 6시를 하루의 경계로 삼습니다.

실제 시각앱이 보는 날짜
8월 27일 새벽 3시8월 26일 (아직 전날 근무)
8월 27일 오전 7시8월 27일

06시에 자동으로 일어나는 일

  • 공사중 → 공사전으로 초기화
  • 작업 연장 기록 해제
  • 수동으로 켠 TODAY 해제
  • 기간이 끝난 공사는 목록에서 정리

체감온도 기록은 지워지지 않습니다.

9. 관리자 기능

❓ 버튼 → 🔑 관리자 모드 활성에서 코드를 입력하면 열립니다. 한 번 인증하면 그 휴대폰에서는 계속 유지됩니다.

관리자 (레벨2)

  • 감독자 연락처 조회 · 전화 바로 걸기
  • 공지사항 작성

마스터 (레벨3)

  • 주말공사 엑셀 업로드
  • 전체 초기화 (암호 재확인 필요)
  • 접속 현황 조회
  • 연락처 관리 · 전체 내보내기

10. 자주 묻는 질문

내가 체크한 게 다른 사람에게도 보이나요?

네. 모든 감독자가 같은 목록을 함께 봅니다. 다만 여러 사람이 동시에 입력해도 서로 지워지지 않도록 처리되어 있습니다.

공사 목록이 안 보입니다

두 가지 경우입니다.

  • "휴일 공사 기간이 아닙니다" — 상단 날짜를 옮기면 예정 공사를 볼 수 있습니다. 공사 목록은 매주 수요일 오후에 업데이트되고, 금요일 오후에 추가 반영됩니다.
  • "공사 목록이 확정되지 않았습니다" — 아직 엑셀이 올라오지 않은 상태입니다.

다른 공장 공사도 보고 싶습니다

감독자는 담당 공장 1개만 볼 수 있습니다. 변경이 필요하면 🏭 내 공장에서 다른 공장으로 바꾸면 됩니다.

화면이 안 열리거나 검은 화면이 뜹니다

예전 버전이 휴대폰에 남아 생기는 문제입니다.

  1. 홈 화면 아이콘 삭제
  2. 크롬 → 설정 → 인터넷 사용 기록 삭제
  3. 주소를 다시 입력해 접속

건의사항이 있습니다

❓ 버튼 → 💬 문의·불편사항에서 익명 게시판으로 남기실 수 있습니다. 로그인이 필요 없고 누가 썼는지 표시되지 않습니다.

## v2.22g (2026-07-31)

> (v2.22d 이후 누적 변경사항을 하나로 통합)

  - 터치 가능함을 알 수 있도록 밑줄 스타일 추가
  - 오늘 날짜일 때 터치해도 아무 동작 없음 (이미 오늘이므로)
- "예정 공사 N건" 문구 글씨 크기 한 단계 확대 (text-sm → text-base)
- **버그 수정**: 기상특보 중 "폭염중대경보"가 배지에 누락되던 문제 해결
  - 원인: 특보 추출 정규식이 `폭염`+`경보/주의보`만 인식하고, 중간에 "중대"가 들어간 "폭염중대경보"는 놓침
- 기상특보 배지 심각도순 정렬: **중대경보 → 경보 → 주의보** 순으로 항상 앞에 표시
- 중대경보는 진한 빨강 + 깜빡임 효과로 다른 특보와 구분 (경보는 기존 빨강, 주의보는 주황)
- 특보 추출 방식을 하드코딩된 재해명 목록 대신 "OO중대경보/경보/주의보" 패턴 전체 인식으로 변경
  → 향후 기상청이 새 특보명을 추가해도 코드 수정 없이 자동 인식됨
- **버그 수정**: 카톡 링크로 접속 시 iOS에서 접속 기기 수가 중복 집계되던 문제 해결
  - 원인: iOS는 카톡 인앱 브라우저에서 자동으로 Safari로 못 옮겨서 "Safari로 열어주세요" 안내 화면을 띄우는데, 이때도 접속 기록 코드가 그대로 실행되어 카톡 인앱 1회 + Safari 1회, 총 2대로 잡혔음
  - Android는 카톡 인앱에서 앱이 뜨기 전에 크롬으로 즉시 강제 이동해서 원래부터 문제없었음
  - 수정: 카톡 iOS 안내 화면 상태(`__KAKAO_IOS__`)일 때는 접속 기록을 건너뛰도록 변경

## v2.19a (2026-07-27)

8월 하계공사(8/1~8/9, 9일치) 대응 중 발견된 날짜 처리 버그를 수정했습니다.
**기존 저장 데이터는 옛 구조이므로, 배포 후 초기화 → 엑셀 재업로드가 필요합니다.**

### 버그 수정

- **9일 이상 기간에서 같은 요일 데이터 소실**
  `dateWorkers` 키가 요일(0~6)이라 8/1(토)이 8/8(토)에, 8/2(일)이 8/9(일)에 덮어써져
  해당 날짜 공사가 목록에서 사라졌습니다. 키가 차 있으면 `+7`씩 밀어 저장하도록 변경.
- **TODAY 배지가 실제 날짜를 무시**
  요일만 대조해, 7월에 8월 공사표의 같은 요일 인원이 잡히며 오늘 작업이 없는데도
  배지가 떴습니다(7/27에 8/3 데이터로 오배지). `findDayWorkers`/`workersOn` 헬퍼를
  신설해 실제 날짜(+월)로 대조합니다.
- **오늘 조회 시 날짜 필터 미적용**
  오늘은 필터 없이 전체를 보여줘 8월 공사가 7월에도 전부 노출됐습니다.
  오늘 포함 모든 날짜에 필터를 적용하되, 진행 중 작업이 사라지지 않도록
  오늘 조회 중 **공사중**인 카드는 배정이 없어도 목록에 남깁니다.
- **등급 뱃지가 넓을 때 카드 뱃지 줄 깨짐**
  `P(A)급` 등에서 NO.가 아랫줄로 밀리고 공사전 뱃지가 세로로 찌그러졌습니다.
  우측 뱃지 그룹에 `flex-shrink-0` + `whitespace-nowrap` 적용, 좌측만 축소되도록 변경.
- **당일 공사 추가가 새 날짜 방식에서 동작 불가** (연쇄 영향)
  기존에는 `{day: 0}`으로 저장해 어떤 날짜와도 매칭되지 않았습니다.
  실제 날짜·월을 기록하도록 수정.

### 기능

- 공사목록 상단 `터치 시 기록/편집` 라벨 삭제
- `오늘 공사 N건 표시 중` 안내문을 항상 표시하고 글씨 확대
- 다른 날짜 조회 시 배지는 그 날짜 기준으로 표시(토글 비활성)

### 예방 조치

- 엑셀 파싱 시 **월(month) 정보를 함께 저장** (제목행에서 추출, 월말→월초 전환 감지)
- 종료일 계산도 저장된 월을 우선 사용해 월 추정 오판 방지
- 화면 표기는 기존과 동일 (`7/27(월)`)
- 구버전 데이터(월 정보 없음)는 **요일+날짜 동시 일치**로만 매칭 —
  다른 달의 같은 날짜가 잘못 잡히지 않도록 처리

### 검증

- 8/1~8/9 9일 전부 정상 조회 / 7/24~7/31 오배지 0건
- 9/24~28, 10/3~5, 10/9~11 일정 정상
- 구버전 데이터(7/25~26) 호환 및 타월 오매칭 없음
- 렌더 테스트: 카드 2건만 표시, 배정 있는 건만 TODAY 배지

## 보안 조치 (2026-07-26)

저장소의 모든 파일이 Cloudflare Pages를 통해 웹에 배포되어,
`supabase-master-v3.sql`(관리자 코드 + 감독자 52명 연락처)이 URL로 직접 접근
가능한 상태였습니다.

- **저장소 구조 3분할** — `public/`(배포 대상) / `server/`(SQL·gs) / `docs/`(문서)
  Cloudflare **Build output directory = `public`** 설정으로 그 외 파일은 배포되지 않음
- 백업문서(`포켓보드PRO_백업.json/.md`)를 **인증정보 제거본**으로 교체
- `index.html` 주석에 남아있던 관리자 코드 문자열 제거 (주석도 소스보기로 노출됨)
- `wrangler.toml` 삭제 (GitHub 연동 방식에서 미사용, 내용도 실제 주소와 불일치)
- `.gitignore` 추가 (zip·시크릿·`desktop.ini` 등 재유입 차단)
- `server/supabase-rotate-codes-v1.sql` 신규 — 관리자 코드·백업 토큰 교체용
  (실제 값은 자리표시자로 두어 저장소에 남기지 않음)
- `server/supabase-master-v3.sql` 상단에 **재실행 금지 경고** 추가
  (v2.5 시점 파일이라 v2.10의 2단계 권한 함수가 빠져 있어, 재실행 시 권한 체계 손상)

> ⚠️ 관리자 코드·백업 토큰은 교체 완료(2026-07-27). 새 값은 저장소에 기록하지 않습니다.

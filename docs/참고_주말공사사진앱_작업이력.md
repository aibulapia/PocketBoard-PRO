## 3. 상세 변경 이력

### 날짜 미상 — Version 0.1
### 버전명: 초기 구조 설계

주요 변경 및 추가 사항:

- 주말 현장 점검 기록용 웹앱 기획.
- 현장별 공사 기록 관리 구조 설계.
- 현장명과 위치를 저장하는 프로젝트 개념 도입.
- 현장 점검 결과를 메모와 사진으로 기록하도록 설계.
- 단일 HTML 파일 기반의 간단한 배포 구조 채택.
- 별도 서버 없이 Supabase를 백엔드로 사용하는 방향 확정.
- 모바일 현장 사용을 고려한 사진 업로드 중심의 작업 흐름 구상.

### 날짜 미상 — Version 0.2
### 버전명: Supabase 프로젝트 구성

주요 변경 및 추가 사항:

- Supabase 프로젝트 생성.
- 프로젝트 URL과 클라이언트용 공개 키 확인.
- 프론트엔드와 Supabase 연결 환경 구성.
- 사용자 인증과 데이터베이스를 Supabase 중심으로 통합.
- 현장 사진을 Supabase Storage에 저장하는 구조 설계.
- 현장별 사진 폴더 구분 규칙 수립.
- 업로드 시각과 파일명을 조합한 사진 파일명 규칙 구성.
- 사진 저장 버킷 구성.

### 날짜 미상 — Version 0.3
### 버전명: 데이터 구조 설계

주요 변경 및 추가 사항:

- `profiles` 사용자 프로필 테이블 구조 설계.
- `projects` 공사 현장 테이블 구조 설계.
- `reports` 현장 보고서 테이블 구조 설계.
- Supabase 인증 사용자와 프로필 연결 구조 설계.
- 하나의 현장에 여러 작업 보고서를 등록할 수 있도록 구성.
- 하나의 보고서에 여러 사진을 연결하도록 설계.
- 사용자 권한을 `admin`과 `user`로 구분.
- 향후 관리자 전용 기능을 확장할 수 있도록 권한 구조 마련.

### 날짜 미상 — Version 0.4
### 버전명: Google 로그인 도입

주요 변경 및 추가 사항:

- Google OAuth 클라이언트 생성.
- Google Cloud 프로젝트에서 OAuth 설정.
- Netlify 배포 주소를 OAuth 허용 도메인으로 등록.
- Supabase Auth에서 Google Provider 활성화.
- Supabase 인증 콜백 주소 등록.
- 로그인 완료 후 앱 주소로 돌아오도록 리디렉션 구성.
- Google 로그인 버튼과 인증 흐름 연결.

인증 설정:

- Supabase Site URL을 Netlify 배포 주소로 지정.
- Redirect URL을 Netlify 배포 주소로 지정.
- Google 승인된 JavaScript 원본 등록.
- Google 승인된 리디렉션 URI 등록.

### 날짜 미상 — Version 0.5
### 버전명: 카카오 로그인 도입

주요 변경 및 추가 사항:

- Supabase Auth에서 Kakao Provider 활성화.
- 카카오 로그인용 리디렉션 흐름 구성.
- Google 로그인과 동일한 앱 진입 구조 적용.
- 국내 사용자 편의를 고려해 카카오 로그인 추가.
- 소셜 로그인 후 사용자 세션을 앱에서 처리하는 구조 마련.

### 날짜 미상 — Version 0.6
### 버전명: 로그인 후 처리 및 사용자 세션 구성

주요 변경 및 추가 사항:

- 로그인 완료 후 현재 사용자 세션 확인.
- 로그인 상태에 따른 화면 분기 구조 설계.
- 인증되지 않은 사용자는 로그인 화면 표시.
- 인증된 사용자는 현장 관리 화면으로 진입.
- 최초 로그인 사용자의 프로필 생성 처리 방향 구성.
- 로그아웃과 세션 종료 흐름 구성.
- 로그인 버튼 클릭 후 OAuth 인증으로 이동하도록 연결.

### 날짜 미상 — Version 0.7
### 버전명: 현장 관리 기능 설계

주요 변경 및 추가 사항:

- 공사 현장 목록 관리 구조 구성.
- 현장명과 위치를 입력해 현장 등록.
- 등록된 현장 선택 기능 구성.
- 선택된 현장에 대한 작업 기록 작성 흐름 설계.
- 현장별 기록과 사진을 분리해 조회할 수 있도록 구성.
- 생성자와 생성일을 저장할 수 있도록 데이터 구조 연결.
- 관리자 권한을 현장 관리 제어에 사용할 수 있도록 설계.

### 날짜 미상 — Version 0.8
### 버전명: 현장 보고서 및 사진 기록 기능

주요 변경 및 추가 사항:

- 현장 메모 입력 기능 구성.
- 현장 사진 여러 장 업로드 기능 구성.
- 사진 업로드 후 Storage 공개 URL 저장.
- 보고서와 사진을 하나의 기록 단위로 관리.
- 현장별 보고서 목록 조회 구조 구성.
- 작업일지에 사진과 메모를 함께 남길 수 있도록 구성.
- 현장 점검 후 모바일에서 바로 기록하는 사용 흐름 반영.

### 날짜 미상 — Version 0.9
### 버전명: Netlify 초기 배포

주요 변경 및 추가 사항:

- 단일 HTML 파일을 Netlify에 배포.
- Netlify Drop 방식으로 최초 배포.
- 배포 주소 확보.
- 실제 배포 환경에서 Supabase 연결 구조 확인.
- OAuth 리디렉션 기준 주소를 Netlify 배포 주소로 통일.
- 로컬 개발 환경과 실제 배포 환경의 주소 차이를 줄이도록 설정.

### 날짜 미상 — Version 0.9.1
### 버전명: 인증 설정 보완

주요 변경 및 추가 사항:

- Supabase 클라이언트 키 설정 정리.
- Google 로그인에 명시적인 리디렉션 주소 추가.
- 카카오 로그인에도 동일한 리디렉션 주소 추가.
- 로그인 이후 앱으로 복귀하는 흐름 보완.
- Supabase와 Google Cloud Console의 주소 설정 일치 여부 확인.
- 인증 Provider 활성화 상태 확인.

### 2026-08-21 기준 — Version 0.9.2
### 버전명: 로그인 동작 오류 확인 및 배포본 점검

확인된 문제:

- 현재 Netlify에 배포된 파일에서 로그인 기능 일부가 누락된 상태.
- 로그인 버튼을 눌러도 반응하지 않는 문제가 확인됨.
- 로그인 완료 처리 관련 내용이 실제 배포본에 반영되지 않은 것으로 파악됨.
- 준비된 완성본과 실제 Netlify 배포본 사이에 차이가 발생함.

추정 원인:

- 최신 완성본이 Netlify Production deploy에 재배포되지 않음.
- 개발 중 수정된 인증 관련 내용이 실제 배포 파일에 포함되지 않음.

필요한 조치:

- 최신 완성본을 Netlify Production deploy에 다시 업로드.
- Google 로그인과 카카오 로그인 재검증.
- 로그인 후 사용자 세션 생성 여부 확인.
- 모바일 브라우저에서 OAuth 리디렉션 확인.

## 8. 현재 결론

2026-08-21 기준 주말공사는 **Version 0.9.2 — 로그인 동작 오류 확인 및 배포본 점검 단계**입니다.

핵심 구조, Supabase 연동 방향, Google·카카오 인증 설정, 현장·보고서·사진 관리 구조는 마련되어 있습니다. 그러나 최신 완성본이 실제 Netlify 배포본에 반영되지 않은 문제가 있어, 현재는 정식 운영 버전이 아닌 베타 단계로 판단합니다.

다음 릴리스는 **Version 0.9.3 — 최신본 재배포 및 로그인 정상화**로 관리하는 것이 적절합니다. 로그인과 기본 데이터 저장·조회 검증이 완료되면 **Version 1.0 — 주말공사 정식 운영 버전**으로 승격할 수 있습니다.

- 과거 각 작업의 실제 달력 날짜는 현재 확보된 기록에 모두 명시되어 있지 않습니다.

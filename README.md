# index.html 변경 내역 — 카톡 복사 기능

## 1. 기존 "점검 결과 전체 복사하기" 버튼 제거
- 화면 하단 고정 버튼(FAB) 및 연결된 `handleClipboardCopy` 함수 삭제

## 2. 카드별 "💬 카톡 복사" 버튼 추가
- 공사 목록의 각 카드 하단에 개별 복사 버튼 추가
- 버튼 클릭 시 `handleKakaoCopy(item)` 실행 → 아래 형식으로 클립보드 복사

```
{공사명 전체}
  {공사위치}  감독-{담당 감독자}
직{직영인원} 일용{일용인원}
```

**예시**
```
41도장 발끝막이 및 안전난간 설치공사
  2F C-01  감독-한경희
직1 일용3
```

- 1번째 줄: 엑셀에서 불러온 **공사명(title) 전체** 그대로 사용
- 2번째 줄: 카드에서 입력한 **공사위치(spotLocation)** + **감독자(assignedSupervisor)**
- 3번째 줄: **직영/일용 인원** — 0명인 항목은 자동 생략, 둘 다 0이면 줄 자체 생략
- 공사위치·감독자 중 하나라도 비어있으면 복사 대신 안내 토스트 표시

## 3. 카드 상세 입력(바텀시트)에 항목 추가
- 👷 **작업 인원** 입력란 추가: 직영 인원 / 일용 인원 (숫자 입력, 각 카드별 저장)
- (※ "카톡 축약 문구" 입력란은 추가했다가, 공사명을 그대로 쓰기로 변경하면서 최종적으로 제거)

## 4. 데이터 구조 변경
- 각 공사 항목(item)에 `directWorkers`(직영인원), `dailyWorkers`(일용인원) 필드 추가
- 저장/불러오기는 기존 로컬·클라우드 저장 로직(storage.js)을 그대로 사용
